- Slice (whoosh, snappy chop, juice squelch)
- Perfect (crystalline shimmer)
- Combo (harmonic scale progression)
- Bomb (sub-bass drop, saturated blast)
- Button (tactile Apple-style UI tap)
- GameOver (cinematic descending resonance)
- Ambient Drone (warm low-pass filtered soundscape)
